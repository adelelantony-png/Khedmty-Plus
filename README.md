# خدمتي برو - خدمة إعداد الخدام

منصة ويب لمتابعة الحضور والنوتة الروحية وقراءة الكتاب المقدس والشيتات والدرجات.
المسار: **GitHub ← Vercel ← Firestore**، مع العمل أوفلاين والتثبيت كتطبيق (Android وiPhone).

## حالة المشروع

| المرحلة | الحالة |
|---|---|
| 0. ترتيب المستودع | منتهية |
| 1. تجهيز Firebase (قاعدة Firestore وقواعد الأمان وفحص الاتصال) | جارية، راجع `docs/PHASE1-FIREBASE.md` |
| 2. الدخول الحقيقي (Custom Token) وإلغاء كلمة مرور الأدمن الافتراضية | لم تبدأ |
| 3. صفحات المخدوم على Firestore مع الأوفلاين (ومنها شاشة «نتائجي») | لم تبدأ |
| 4. PWA: Service Worker والتثبيت وصفحة الأوفلاين | لم تبدأ |
| 5. التجاوب مع كل الشاشات | لم تبدأ |
| 6. ترحيل لوحة الخدام، والدرجات، والتحفيز المخفي، واستيراد وتصدير Excel | لم تبدأ |
| 7. الأمان والتشغيل | لم تبدأ |
| 8. اختبار القبول | لم تبدأ |

> **مهم:** هذه الحزمة هي المشروع كما هو الآن (المرحلتان 0 و1 + المواصفات). التطبيق يعمل بالبيانات المحلية
> في كل جهاز (`localStorage`) إلى أن تكتمل المراحل 2 و3 و6. ما تسجله على جهاز لا يظهر على جهاز آخر قبل ذلك.

## النشر

1. **GitHub**: أنشئ مستودعاً Private وارفع محتويات هذا المجلد (بحيث تظهر `public` و`api` في الجذر).
2. **Vercel**: Add New ← Project ← اختر المستودع ← Deploy (من غير تغيير الإعدادات).
3. **متغيرات Vercel** (Settings ← Environment Variables) ثم Redeploy:

| الاسم | القيمة |
|---|---|
| `FIREBASE_PROJECT_ID` | `khedmety-plus` |
| `FIREBASE_CLIENT_EMAIL` | من ملف مفتاح الخادم (Service account) |
| `FIREBASE_PRIVATE_KEY` | المفتاح الخاص كاملاً من نفس الملف |
| `ADMIN_API_ENABLED` | `false` |

4. افتح `https://<موقعك>.vercel.app/api/health` ويجب أن يظهر `{"ok":true,"firestore":"connected"}`.

**لا ترفع ملف مفتاح الخادم على GitHub ولا ترسله لأحد.**

## ما الذي يعمل الآن

- كل صفحات الواجهة (الدخول، لوحة الخدام، صفحات المخدوم) بالبيانات المحلية.
- أزرار الرجوع تعمل لكل دور (مخدوم، خادم، أدمن).
- `api/admin.js` مغلق عمداً (يرد 403) لأنه بلا تحقق من الصلاحية، ويُفتح بعد المرحلة 2.
- `api/login.js` مؤقت (يرد 501) ويُستبدل في المرحلة 2.

## نواقص معروفة

- `public/bible_plan.json` فيه 3 أيام فقط من 366. المطلوب خطة قراءة الإنجيل السنوية الكاملة.
- كلمة مرور الأدمن الافتراضية ظاهرة في `public/index.html` وتُلغى في المرحلة 2.
- صفحات الخدام بلا فحص دخول إلى أن تُربط بتسجيل الدخول وقواعد Firestore.
- `recover.html` و`barcode.html` و`admin_subjects.html` بلا أزرار تصل إليها بعد.
- استيراد الخدام من Excel غير موجود (النموذج فقط)، ويُضاف في المرحلة 6.

## قرارات معلّقة

1. حد النجاح يُطبَّق على المجموع، أم كل خانة على حدة، أم التحريري فقط؟
2. هل يرى المخدوم سطر «رأفة +N» أم الدرجة النهائية فقط؟
3. قرار الدومين النهائي قبل توزيع التطبيق (التثبيت مرتبط بالرابط).
